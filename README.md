
# Projectile Motion Based Construction Material Delivery Simulator

## University Physics Project

An interactive Streamlit application demonstrating projectile motion
and its application to construction material delivery concepts.

## Project Development Team

- BSPHY-2025-017

## Features

- Projectile motion simulation
- Adjustable launch velocity and angle
- Launch position and gravity controls
- Time of flight calculation
- Maximum height calculation
- Horizontal range calculation
- Projectile trajectory graph
- Vector analysis
- Mathematical derivations
- Presentation content
- CSV results download

## Technologies

- Python
- Streamlit
- NumPy
- Pandas
- Plotly

## Run Locally

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Create a GitHub repository.
2. Upload app.py.
3. Upload requirements.txt.
4. Upload readme.md.
5. Open https://share.streamlit.io/
6. Sign in using GitHub.
7. Select your repository.
8. Select app.py as the main file.
9. Click Deploy.

## Physics Model

The simulator uses ideal projectile motion equations
and ignores air resistance.

This application is intended for educational purposes.
